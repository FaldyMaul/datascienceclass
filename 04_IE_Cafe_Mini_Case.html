Step 3 · explain it with CRISP-DM

How you would present this answer

You do not need to analyse data or build a model for the case — you need to explain your steps and what you expect to happen.

1 · BUSINESS UNDERSTANDING

Owner cannot name the featured products; margin is below target. Goal: raise monthly profit without more customers.

2 · DATA UNDERSTANDING

Transactions list items in one text cell; the cost table has one row per product. Write a data dictionary first.

3 · DATA PREPARATION

Split the item text into rows, fix typos and “x 2” quantities, remove refunds, then join to cost by product name.

4 · MODELLING

No machine learning: count units, compute margin, compare with the menu average. Four boxes.

5 · EVALUATION

Does the map match what staff see every day? Check with the owner before changing the menu.

6 · DEPLOYMENT

Feature the stars, bundle a puzzle with a star, reprice one workhorse. Measure next month and repeat.

Prices and costs follow the teaching case. Units sold per month are invented for this exercise, so the positions on the map are illustrative. Method: menu engineering (Kasavana & Smith, 1982). Other valid answers — forecasting, stock analysis, review sentiment, basket analysis — use the same six steps.
